The Problem

African institutions are exposed.
The current model isn't helping.

Zimbabwe's largest mobile network got hacked. Banks were breached. Companies lost billions. And the same vulnerabilities keep being exploited — because the institutions that need security most simply cannot afford the existing solutions.

$$$
Retainer models punish the honest
Traditional consultancy firms charge fixed monthly fees regardless of whether any vulnerability is ever found. For a bank in Harare or a mobile operator running on thin margins, this is simply unaffordable.
⊘
Skills gap on the continent
Africa produces capable security researchers who are largely excluded from global bounty platforms, or participate without proper verification or fair recognition. That talent goes underutilized.
∞
The cycle repeats
Without accessible, results-based security testing, the same classes of vulnerabilities — injection flaws, broken authentication, misconfigured APIs — are found by attackers before defenders. Over and over.
The criminals walk away.
The companies have already paid.
Paying for security theater doesn't make you safer. Paying for real, found, documented, and fixed vulnerabilities does. That's the only model that makes sense here.
How It Works

Simple. Transparent. Fair.

Three clean steps from onboarding to a fixed vulnerability — with a clear paper trail, verified researchers, and payment only when something is actually found.

Step 01
⚙
Company defines scope
The company signs up, defines exactly what is in scope — which APIs, apps, or systems — and agrees on reward bands by severity. No ambiguity. Full control.
Step 02
◎
Vetted researchers hunt
Our verified, background-checked researchers — globally recruited with active African inclusion — probe within agreed scope using industry-standard methods. All identities are confirmed. All conduct is tracked.
Step 03
✓
Pay only for real findings
A valid vulnerability report is triaged, verified, and classified. The company pays the researcher's reward plus the Elites platform fee. If nothing is found, nothing is owed.
